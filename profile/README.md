## Research areas

- **Time-series forecasting**: multivariate forecasting, precipitation nowcasting, epidemic forecasting, and forecast-driven decisions.
- **Related research**: physiological signal reconstruction, satellite imagery, and visual grounding.

Collaborators include Hokkaido University's Media Dynamics Laboratory, LTS, Inc., and ME-Lab Japan, Inc. See individual papers for details.
